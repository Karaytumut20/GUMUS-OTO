## Teknik SEO Uygulama Parametreleri

1. **Kanonikleştirme (Canonical):** Tüm sayfalarda self-referencing mutlak canonical tanımlanmıştır (`https://gumusotokurtarma.com/.../`).
2. **Trailing Slash Tutarlılığı:** `next.config.mjs` içinde `trailingSlash: true` ile sitemap ve URL yapıları tamamen senkronizedir.
3. **Structured Data (JSON-LD):** `AutomotiveBusiness`, `WebSite`, `BreadcrumbList`, ve `Service` tipleri şema standardına uygun olarak eklenmiştir.
4. **Resim Optimizasyonu:** Modern WebP formatları (`public/images/gumus-oto-kurtarma-logo.webp`), OG Image (`public/images/og-image.png`) eksiksiz tanımlanmıştır.
